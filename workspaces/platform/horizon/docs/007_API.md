# API Documentation

## Overview

The Horizon Platform exposes REST, WebSocket, and gRPC APIs for different use cases:

- **REST API**: CRUD operations, authentication, deployments
- **WebSocket API (Crosis)**: Real-time IDE communication
- **gRPC API**: Internal service-to-service communication

## REST API

### Base URL

```
Production: https://api.horizonplatform.io/v1
Staging:    https://api.staging.horizonplatform.io/v1
```

### Authentication

All API requests require authentication via Bearer token:

```http
Authorization: Bearer {access_token}
```

Obtain tokens via OAuth 2.0:

```http
POST /oauth/token
Content-Type: application/x-www-form-urlencoded

grant_type=authorization_code
&code={authorization_code}
&redirect_uri={redirect_uri}
&client_id={client_id}
&client_secret={client_secret}
```

### Rate Limiting

| Tier | Requests/min | Burst |
|------|--------------|-------|
| Free | 60 | 10 |
| Starter | 300 | 50 |
| Pro | 1000 | 100 |
| Enterprise | Custom | Custom |

Rate limit headers:

```http
X-RateLimit-Limit: 1000

```

### Workspaces

#### Create Workspace

```http
POST /workspaces
Content-Type: application/json

{
  "name": "my-project",
  "language": "python",
  "template": "flask-starter",
  "isPublic": false
}
```

Response:

```json
{
  "id": "ws_abc123",
  "name": "my-project",
  "language": "python",
  "url": "https://horizonplatform.io/@username/my-project",
  "createdAt": "2024-01-15T10:30:00Z"
}
```

#### Get Workspace

```http
GET /workspaces/{id}
```

#### List Workspaces

```http
GET /workspaces?page=1&limit=20&sort=createdAt:desc
```

#### Update Workspace

```http
PATCH /workspaces/{id}
Content-Type: application/json

{
  "name": "new-name",
  "isPublic": true
}
```

#### Delete Workspace

```http
DELETE /workspaces/{id}
```

#### Fork Workspace

```http
POST /workspaces/{id}/fork
Content-Type: application/json

{
  "name": "forked-project"
}
```

### Files

```http
GET /workspaces/{id}/files?path=/src
```

Response:

```json
{
  "files": [
    {
      "name": "main.py",
      "path": "/src/main.py",
      "type": "file",
      "size": 1024,
      "modifiedAt": "2024-01-15T10:30:00Z"
    },
    {
      "name": "utils",
      "path": "/src/utils",
      "type": "directory"
    }
  ]
}
```

#### Read File

```http
GET /workspaces/{id}/files/{path}
Accept: application/octet-stream
```

#### Write File

```http
PUT /workspaces/{id}/files/{path}
Content-Type: application/octet-stream

{file_content}
```

#### Delete File

```http
DELETE /workspaces/{id}/files/{path}
```

## WebSocket API (Crosis Protocol)

### Connection

```typescript
import { Client } from '@horizon/crosis';

const client = new Client<Context>();

await client.open({
  fetchConnectionMetadata: async () => ({
    token: await getToken(),
    gurl: 'wss://workspace.horizonplatform.io',
    conmanURL: 'https://conman.horizonplatform.io'
  })
});
```

### Channels

#### Shell Channel

```typescript
// Open shell
const shell = await client.openChannel({
  service: 'shell',
  name: 'shell-0'
});

// Send input
shell.send({ input: 'echo "Hello"\n' });

// Receive output
shell.onCommand((cmd) => {
  if (cmd.output) {
    console.log(cmd.output);
  }
});

// Resize terminal
shell.send({
  resize: { cols: 80, rows: 24 }
});
```

#### Files Channel

```typescript
const files = await client.openChannel({ service: 'files' });

// Read file
files.send({
  read: { path: '/src/main.py' }
});

files.onCommand((cmd) => {
  if (cmd.file) {
    console.log(cmd.file.content);
  }
});

// Write file
files.send({
  write: {
    path: '/src/main.py',
    content: 'print("Hello")'
  }
});

// Watch for changes
files.send({
  watch: { path: '/src' }
});
```

#### LSP Channel

```typescript
const lsp = await client.openChannel({ service: 'lsp' });

// Initialize
lsp.send({
  request: {
    id: 1,
    method: 'initialize',
    params: {
      rootUri: 'file:///home/runner/workspace',
      capabilities: {}
    }
  }
});

// Completion request
lsp.send({
  request: {
    id: 2,
    method: 'textDocument/completion',
    params: {
      textDocument: { uri: 'file:///src/main.py' },
      position: { line: 10, character: 5 }
    }
  }
});
```

#### Exec Channel

```typescript
const exec = await client.openChannel({ service: 'exec' });

// Run command
exec.send({
  exec: {
    args: ['python', 'main.py'],
    env: { DEBUG: 'true' }
  }
});

// Handle output
exec.onCommand((cmd) => {
  if (cmd.output) console.log(cmd.output);
  if (cmd.exitCode !== undefined) {
    console.log(`Exited with code ${cmd.exitCode}`);
  }
});

// Send signal
exec.send({ signal: 2 }); // SIGINT
```

### Protocol Messages (Protobuf)

```protobuf
message Command {
  oneof body {
    // Shell
    string input = 1;
    string output = 2;
    Resize resize = 3;

    // Files
    ReadRequest read = 10;
    WriteRequest write = 11;
    FileResponse file = 12;
    WatchRequest watch = 13;
    FileEvent fileEvent = 14;

    // Exec
    ExecRequest exec = 20;
    int32 signal = 21;
    int32 exitCode = 22;

    // LSP
    LSPRequest request = 30;
    LSPResponse response = 31;
  }
}

message Resize {
  int32 cols = 1;
  int32 rows = 2;
}

message ReadRequest {
  string path = 1;
}

message WriteRequest {
  string path = 1;
  bytes content = 2;
}
```

## Event Streaming

### NATS JetStream Subjects

Events are published to NATS JetStream for durable streaming (see [ADR-018](../adrs/018_NATS_Messaging_Platform.md)):

| Subject | Description | Stream |
|---------|-------------|--------|
| `horizon.events.workspace.created` | New workspace | WORKSPACE_EVENTS |
| `horizon.events.container.started` | Container started | CONTAINER_EVENTS |
| `horizon.events.file.changed` | File modification | WORKSPACE_EVENTS |
| `horizon.events.deployment.status` | Deployment updates | DEPLOYMENT_EVENTS |
| `horizon.events.collaboration.presence` | User presence | COLLABORATION_EVENTS |
| `horizon.events.ai.request` | AI request made | NOTIFICATION_EVENTS |

### NATS KV Buckets (Real-time State)

| Bucket | Purpose | TTL |
|--------|---------|-----|
| PRESENCE | User online status | 30s |
| CURSORS | Cursor positions | 5s |
| SESSIONS | Active sessions | None |
| COLLAB_STATE | Room state | 24h |

## Error Responses

### Error Format

```json
{
  "error": {
    "code": "WORKSPACE_NOT_FOUND",
    "message": "Workspace not found",
    "details": {
      "workspaceId": "ws_invalid"
    }
  }
}
```

### Error Codes

| Code | HTTP Status | Description |
|------|-------------|-------------|
| `UNAUTHORIZED` | 401 | Invalid or missing token |
| `FORBIDDEN` | 403 | Insufficient permissions |
| `NOT_FOUND` | 404 | Resource not found |
| `RATE_LIMITED` | 429 | Rate limit exceeded |
| `VALIDATION_ERROR` | 400 | Invalid request |
| `INTERNAL_ERROR` | 500 | Server error |

## SDKs

Official SDKs available:

- **JavaScript/TypeScript**: `npm install @horizon/sdk`
- **Python**: `pip install horizon-sdk`
- **Go**: `go get github.com/horizon/go-sdk`

```typescript
// JavaScript SDK example
import { Horizon } from '@horizon/sdk';

const client = new Horizon({ token: 'your-token' });

const workspace = await client.workspaces.create({
  name: 'my-project',
  language: 'python',
});

await workspace.files.write('/main.py', 'print("Hello")');
const result = await workspace.run('python main.py');
console.log(result.output);
```
