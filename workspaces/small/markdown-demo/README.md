# Markdown Demo Example

This example demonstrates all Markdown features supported by the structurizr-rs documentation renderer.

## Purpose

Use this example to:

- Test markdown rendering features
- Verify CSS styling for various elements
- Serve as a reference for documentation authors
- Validate GFM (GitHub Flavored Markdown) support

## Features Demonstrated

- Headers (h1-h6)
- Text formatting (bold, italic, strikethrough)
- Lists (ordered, unordered, nested, task lists)
- Tables with alignment
- Code blocks with syntax highlighting
- Blockquotes
- Links and images
- Footnotes
- Horizontal rules
- Description lists

## Running

```bash
./serve.sh
```

Then navigate to the **Documentation** page to see all markdown features rendered.
